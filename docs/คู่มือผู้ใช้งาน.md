# คู่มือผู้ใช้งาน DATA BSTH

ระบบแสดงสถิติการให้บริการของโรงพยาบาลบางเสาธง เช่น ผู้ป่วยนอก ผู้ป่วยใน ห้องฉุกเฉิน คิว และคลินิกต่าง ๆ ในรูปตัวเลข กราฟ และตาราง

> **ตอนนี้ระบบยังแสดงข้อมูลจำลอง** ชื่อคลินิก ชื่อโรค และปริมาณทำให้ใกล้เคียงของจริงใน HOSxP แต่ยังไม่ใช่ตัวเลขจริง ห้ามนำไปใช้รายงานหรืออ้างอิง ทุกครั้งที่เปิดเว็บจะมีหน้าต่างแจ้งเรื่องนี้

เปิดเว็บด้วย Chrome หรือ Edge ตามลิงก์ที่ฝ่าย IT แจ้ง

| | ไม่ login (ผู้เยี่ยมชม) | login ด้วยบัญชี HOSxP |
|---|---|---|
| หน้าแรก และหน้าแผนกทุกหน้า | ✅ | ✅ |
| เลือกช่วงวันที่ | ✅ | ✅ |
| ส่งออก Excel / พิมพ์ PDF | – (ปุ่มเป็นรูปแม่กุญแจ) | ✅ |
| ค้นหาผู้ป่วยตามโรค (ICD-10) | – | ✅ |
| แจ้งปัญหา / ติดตามเรื่องที่แจ้ง | – | ✅ |
| เห็น QR Code LINE ของผู้พัฒนา | – | ✅ |

**การ login**
- ใช้ชื่อผู้ใช้และรหัสผ่านเดียวกับ HOSxP
- ถ้ากดปุ่มที่มีแม่กุญแจ ระบบจะพาไปหน้า login แล้วพากลับมาหน้าเดิม
- ถ้าใส่รหัสผิดหลายครั้ง จะถูกพักการ login 5 นาที
- ถ้าไม่ได้ใช้งานเกิน 30 นาที ระบบออกจากระบบให้อัตโนมัติ กลับเป็นผู้เยี่ยมชม

## 3. เลือกช่วงวันที่

มุมขวาบนของหน้ารายงานมีตัวเลือกช่วงวันที่ 2 แบบ

- **ปีงบประมาณ:** เลือกปีงบ (1 ต.ค. – 30 ก.ย.) ปีปัจจุบันจะตัดถึงวันนี้
- **กรองระหว่างวัน:** เลือกวันเริ่มต้นและวันสิ้นสุดเอง

วันที่ทั้งระบบเป็นปี พ.ศ. รูปแบบ วัน/เดือน/ปี เช่น 01/10/2569 ปุ่ม ⟳ ข้างตัวเลือกใช้โหลดข้อมูลล่าสุด

**ตัวเลขเปลี่ยนแปลง (% สีเขียว/แดง ใต้ตัวเลข):** เทียบกับช่วงก่อนหน้าที่ยาวเท่ากัน ถ้าไม่มีข้อมูลให้เทียบจะไม่แสดง

## 4. ใช้งานกล่องรายงาน

- **Top 10 / 20 / 50:** กล่องอันดับ เช่น 10 อันดับโรค เลือกจำนวนอันดับได้
- **Excel:** ดาวน์โหลดข้อมูลในกล่องนั้นเป็นไฟล์ Excel ตามที่เห็นบนจอ
- **พิมพ์ / PDF:** พิมพ์เฉพาะกล่องนั้น หรือเลือก "บันทึกเป็น PDF" ในหน้าต่างพิมพ์
- **ชี้เมาส์บนกราฟ:** ดูตัวเลขของจุดนั้น

### นัดหมายรายคลินิก (หน้า OPD)

| แผง | ปุ่มวันที่เลือกได้ | แสดง |
|---|---|---|
| นัดหมายรายคลินิก — วันนี้ | วันนี้ และย้อนหลัง | นัด · มาแล้ว · ยังไม่มา (วันที่ผ่านไปแล้ว: มา · ไม่มา) |
| นัดหมายรายคลินิก — พรุ่งนี้ | วันนี้ ถึงล่วงหน้า 1 ปี | จำนวนนัด และสัดส่วนของแต่ละคลินิก |

ปุ่มใต้ปฏิทิน ("วันนี้" / "พรุ่งนี้") กดกลับมาวันเริ่มต้นได้ทันที

## 5. แจ้งปัญหา / ข้อเสนอแนะ (ต้อง login)

1. ไปที่เมนู **ติดต่อผู้พัฒนา**
2. เลือกประเภท: แจ้งปัญหาการใช้งาน / ข้อมูลไม่ถูกต้อง / ข้อเสนอแนะ / อื่น ๆ
3. เลือกหน้าที่เกี่ยวข้อง แล้วพิมพ์รายละเอียด
4. แนบรูปหน้าจอได้สูงสุด 3 รูป (ระบบย่อรูปให้อัตโนมัติ)
5. **ช่องทางติดต่อกลับ** (บังคับทั้งสองช่อง)
   - **เบอร์โทร:** พิมพ์แค่ตัวเลข ระบบใส่ขีดให้เอง เช่น 098-756-4785 หรือ 02-123-4567
   - **LINE:** เลือกกรอก **LINE ID** หรือแนบ **รูป QR Code LINE** อย่างใดอย่างหนึ่ง
6. กดส่ง

### ติดตามเรื่องที่แจ้ง

- เมนู **เรื่องที่แจ้ง** แสดงทุกเรื่องที่คุณส่ง พร้อมสถานะ: ยังไม่ดำเนินการ → กำลังดำเนินการ → ดำเนินการแล้ว
- แต่ละเรื่องมีไทม์ไลน์ และข้อความตอบกลับจากผู้ดูแล (💬)
- เมื่อผู้ดูแลอัปเดตเรื่องของคุณ จะมีตัวเลขขึ้นที่ **กระดิ่ง** มุมขวาบน และป้าย "ใหม่" บนเรื่องนั้น

## 6. สำหรับผู้ดูแลระบบ

ผู้ดูแลคือผู้ใช้ที่อยู่กลุ่ม "ผู้ดูแลระบบ" ใน HOSxP จะเห็นเมนูเพิ่ม 4 หน้า

| หน้า | ใช้ทำอะไร |
|---|---|
| **ผู้ใช้งานระบบ** | ทุกคนที่เคย login (ไม่นับผู้เยี่ยมชม) พร้อมสถานะ 🟣 ใช้งานอยู่ (กดใช้งานภายใน 5 นาที) · 🟠 เปิดค้างไว้ (เปิดเว็บอยู่แต่ไม่ได้กดอะไร) · ⚪ ออฟไลน์ (ออกจากระบบ / session หมดอายุ / ปิดเว็บเกิน 3 นาที) · ค้นหา กรองสถานะ เรียงคอลัมน์ได้ · อัปเดตเองทุก 30 วินาที · ปุ่ม **บังคับออก** (เฉพาะคนที่ออนไลน์ บังคับตัวเองไม่ได้) ทำให้คนนั้นหลุดทุกเครื่องภายใน 1 นาที แล้ว login ใหม่ได้ทันที — บันทึกในประวัติการใช้งาน |
| **แจ้งปัญหา / ข้อเสนอแนะ** | ดูเรื่องที่ผู้ใช้แจ้ง (กรองตามสถานะ) · เบอร์โทรกดโทรได้ · ดู LINE ID / QR · กดปุ่มสถานะเพื่อเปลี่ยนสถานะ พร้อมพิมพ์ข้อความตอบกลับ |
| **สถานะข้อมูล** | ดูรอบเตรียมข้อมูลล่าสุด/ถัดไป · รายงานที่โหลดช้า · ปุ่มดึงข้อมูลใหม่ (กดได้ทุก 10 นาที) |
| **ประวัติการใช้งาน** | ใครเข้าระบบ เปิดหน้าไหน ส่งออกไฟล์อะไร · กรองตามผู้ใช้ / ประเภท · กดหัวคอลัมน์ "เวลา" เพื่อสลับล่าสุดก่อน/เก่าสุดก่อน |

- เรื่องแจ้งใหม่ส่งแจ้งเตือนเข้า Telegram ด้วย ถ้าฝ่าย IT ตั้งค่าไว้
- ระบบลบรูปแนบของเรื่องที่ "ดำเนินการแล้ว" ครบ 90 วันอัตโนมัติ ข้อความของเรื่องยังอยู่
- หน้าประวัติการใช้งานแสดงย้อนหลัง 180 วัน ที่เก่ากว่านั้นถูกย้ายเข้าคลัง ไม่ได้ลบ ขอดูได้จากฝ่าย IT

## 7. คำถามที่พบบ่อย

**ปุ่ม Excel / PDF เป็นรูปแม่กุญแจ**
ยังไม่ได้ login หรือ session หมดอายุ ให้ login ใหม่

**ตัวเลขไม่ตรงกับรายงานใน HOSxP**
ช่วงนี้ระบบยังเป็นข้อมูลจำลอง เมื่อเปลี่ยนเป็นข้อมูลจริงแล้วยังไม่ตรง ให้แจ้งผ่านเมนูติดต่อผู้พัฒนา เลือกประเภท "ข้อมูลไม่ถูกต้อง" และแนบภาพหน้าจอทั้งสองฝั่ง

**มีป้าย "ข้อมูลอาจไม่เป็นปัจจุบัน"**
ระบบดึงข้อมูลรอบล่าสุดไม่สำเร็จ จึงแสดงชุดเดิมไว้ก่อน รอสักครู่แล้วกด ⟳ ถ้ายังขึ้นอยู่ให้แจ้งฝ่าย IT

**ส่งแจ้งปัญหาไม่ได้ ขึ้นว่าเบอร์โทรไม่ถูกต้อง**
ต้องเป็นเบอร์ไทย 9–10 หลัก ขึ้นต้นด้วย 0 ไม่รับรูปแบบ +66
